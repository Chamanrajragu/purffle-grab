Frequently Asked Questions

Everything you need to know about PurffleGrab.

Is PurffleGrab really free?
Yes, 100% free and open-source under the MIT license. No hidden costs, no premium version, no subscriptions, no ads. Ever.
What formats does PurffleGrab support?
Audio: MP3, M4A (AAC), FLAC (lossless), WAV, Opus, OGG Vorbis, AAC. Video: MP4 (up to 4K), MKV, WebM. Audio bitrates from 64 to 320 kbps. Video quality from 360p to 2160p (4K).
Can I download entire Spotify playlists?
Yes! Paste any Spotify playlist, album, or track link. PurffleGrab reads the track list, finds the best audio match on YouTube, downloads it, and embeds Spotify metadata including cover art, artist, album, and title.
Does it work on Windows 11?
Yes, PurffleGrab works on Windows 10 and Windows 11 (64-bit). It comes as a standard installer with all dependencies (yt-dlp, ffmpeg) bundled — no extra setup required.
Is PurffleGrab safe? Does it contain malware?
PurffleGrab is completely open-source on GitHub — anyone can inspect every line of code. It contains zero telemetry, analytics, or trackers. It bundles yt-dlp and ffmpeg, which are widely-used, trusted open-source tools.
How do I update the download engine?
Go to Settings → Downloader engine → Click "Update engine." This updates the bundled yt-dlp to the latest version, ensuring maximum compatibility with YouTube and other sites.
Can I convert files after downloading?
Yes! PurffleGrab has a built-in format converter. Drop any audio or video file and convert it to MP3, FLAC, M4A, WAV, Opus, OGG, MP4, WebM, or MKV.
Does it support subtitles?
Yes, you can download and embed subtitles in any available language. It supports both manual and auto-generated YouTube captions, converted to SRT format.
What is SponsorBlock?
SponsorBlock is a community-driven database of sponsor segments in YouTube videos. When enabled, PurffleGrab automatically removes sponsor reads, intros, outros, and self-promotions from downloaded videos.
Is this legal?
PurffleGrab is a tool for personal use. Please respect copyright law and the terms of service of the platforms you download from. We encourage using it only for content you have the right to download.
